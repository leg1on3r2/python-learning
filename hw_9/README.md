# Работа 9. Прогнозирование стоимости квартиры + интерфейс Streamlit

Модель предсказывает стоимость квартиры по площади, числу комнат, этажу и локации,
а интерфейс на Streamlit позволяет ввести параметры и получить прогноз по кнопке.

## Структура

| Файл | Назначение |
|---|---|
| `data.py` | загрузка и очистка датасета из `DataSet/train_data.zip` |
| `train_model.py` | обучение моделей, метрики, сохранение в `artifacts/` |
| `predict.py` | получение предсказания — используется интерфейсом и из консоли |
| `app.py` | интерфейс Streamlit |
| `проверка.py` | проверка решения запуском: логика предсказания и сам интерфейс |
| `artifacts/model.joblib` | модель, предсказывающая цену (1.9 МБ вместе с квантильными) |
| `artifacts/quantile_low.joblib`, `artifacts/quantile_high.joblib` | модели 10-го и 90-го проценты цены для диапазона прогноза |
| `artifacts/meta.json` | справочники городов, районов, координат и метрики |

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Интерфейс открывается в браузере на `http://localhost:8501`.

Переобучить модель (нужен архив с данными, ~40 секунд):

```bash
python train_model.py
```

Предсказание без интерфейса:

```bash
python predict.py --square 56 --rooms 2 --floor 7 --city Москва --district "Тверской район"
```

Проверка решения:

```bash
python проверка.py
```

## Модель

Градиентный бустинг `HistGradientBoostingRegressor` на 78 848 объявлениях (тестовая выборка —
19 712). Признаки: площадь, число комнат, этаж, широта, долгота, город, район.

- Цены скошены вправо на два порядка, поэтому модель учится на логарифме цены, а результат
  возвращается в рубли через `exp`. Без логарифма ошибку определяли бы единичные дорогие
  объекты, а типовые квартиры предсказывались бы плохо.
- Город и район передаются как категориальные признаки, которые бустинг обрабатывает нативно:
  one-hot раздул бы матрицу, потому что районов больше сотни.
- Две дополнительные модели на тех же признаках предсказывают 10-й и 90-й проценты цены — из
  них складывается диапазон прогноза. Средняя ошибка в рублях у дорогих квартир в разы больше,
  поэтому «плюс-минус MAE» вводил бы в заблуждение.

Качество на отложенной выборке (20% данных, `random_state=42`):

| Метрика | Модель | Бейзлайн |
|---|---|---|
| MAE | 3 220 844 ₽ | 9 831 785 ₽ |
| Медианная ошибка | 1 129 813 ₽ | 4 353 210 ₽ |
| MAPE | 10.58% | 35.1% |
| R² | 0.9269 | 0.466 |

Бейзлайн — медианная цена квадратного метра, умноженная на площадь. Фактическая цена попадает
в показанный интерфейсом диапазон 10–90% в 77.1% случаев.
