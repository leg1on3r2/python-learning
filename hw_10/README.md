# Работа 10. API для модели прогнозирования стоимости квартиры (FastAPI)

Модель предсказывает стоимость квартиры по площади, числу комнат, этажу и локации,
доступ к ней открыт двумя методами — GET и POST, плюс liveness-проба.

Модель переиспользована из работы 9 (условие задания это разрешает): те же файлы
`artifacts/` — градиентный бустинг на логарифме цены и две модели квантилей
для диапазона прогноза.

## Запуск

```bash
pip install -r requirements.txt
uvicorn api:app --reload
```

Интерактивная документация Swagger: `http://127.0.0.1:8000/docs`

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | liveness-проба: `{"status": "ok"}`, если сервис поднялся и модель загрузилась |
| GET | `/predict_get` | прогноз, параметры передаются в строке запроса |
| POST | `/predict_post` | прогноз, параметры передаются в теле запроса (JSON) |

### Пример GET

```bash
curl -G http://127.0.0.1:8000/predict_get \
  --data-urlencode "total_square=56" --data-urlencode "rooms=2" \
  --data-urlencode "floor=7" --data-urlencode "city=Москва" \
  --data-urlencode "district=Тверской район"
```

```json
{
  "price": 30708570.46,
  "price_per_square": 548367.33,
  "low": 24195102.74,
  "high": 35973518.82,
  "model": "HistGradientBoostingRegressor на логарифме цены"
}
```

### Пример POST

```bash
curl -X POST http://127.0.0.1:8000/predict_post \
  -H "Content-Type: application/json" \
  -d '{"total_square": 120, "rooms": 4, "floor": 9, "city": "Химки", "district": "не указан"}'
```

```json
{
  "price": 22512102.06,
  "price_per_square": 187600.85,
  "low": 18225493.96,
  "high": 32884362.89,
  "model": "HistGradientBoostingRegressor на логарифме цены"
}
```

`price` — прогноз стоимости в рублях, `price_per_square` — цена метра, `low` и `high` —
границы диапазона 10–90% из квантильных моделей.

Значения проверяются: площадь ограничена 8–500 м², число комнат 0–15, этаж 1–100,
город и район должны быть из обучающих данных. Иначе ответ 422 с причиной, например
`{"detail": "Неизвестный город: Париж"}`.

## Структура

| Файл | Назначение |
|---|---|
| `api.py` | приложение FastAPI: эндпоинты, модели запроса и ответа |
| `predict.py` | получение предсказания обученной моделью |
| `data.py` | загрузка и очистка датасета (нужен только для переобучения) |
| `train_model.py` | обучение модели, сохранение в `artifacts/` |
| `artifacts/` | модель, квантильные модели и справочники городов и районов |

Чтобы переобучить модель, скачайте архив `train_data.zip` по ссылке из задания и
положите его в папку `DataSet` рядом с проектом, затем выполните `python train_model.py`.
Для запуска API архив не нужен: модель уже обучена и лежит в `artifacts/`.
